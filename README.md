# SIMMETRIKA (simmetrika-mebel.ru): интернет-магазин диванов по ТЗ — исследование и прототип структуры

Фабрика диванов SIMMETRIKA (Москва, Химки, 5 точек продаж) заказала новый сайт: витрина-каталог с заявкой без онлайн-оплаты (ТЗ от 12.10.2026). Текущий сайт — статический экспорт Tilda 2019 года без страниц товаров и без поисковой видимости. Здесь собрано всё, что нужно до начала разработки: разбор ТЗ и исходников, аудит текущего сайта, семантика и выдача Яндекса по Москве, карта сайта, модель каталога, правила URL и индексации, вопросы к заказчику.

**Сайт (превью):** https://takedown-desing.github.io/simmetrika-site/ · код: https://github.com/takedown-desing/simmetrika-site

**Смотреть прототип структуры:** https://takedown-desing.github.io/simmetrika-prototype/

## Как проводилось исследование

1. Исходники: ТЗ на 8 страниц, описание задачи, каталог Egeo, 76 файлов с Яндекс.Диска (листинг через публичный API Диска, недостающие локально 17 файлов докачаны).
2. Текущий сайт: обход всех страниц (`/`, `/straight.html`, `/angular.html`, `/modular.html`), robots, sitemap, заголовки, редиректы http/www, счётчики, PageSpeed Insights mobile и desktop, картинки каталога.
3. Спрос: Wordstat API, регион «Москва и область», 24 seed-маски по 400 фраз. Чистка по промпту S01 (стоп-слова по шести категориям), кластеризация по интенту с привязкой к выдаче.
4. Выдача: Arsenkin check-top, Яндекс Desktop Москва (213), ТОП-10 по 10 якорным запросам. Keys.so по домену — данных нет (видимость 0).
5. Структура: дерево по RULE-URL-STRUCTURE (trailing slash, латиница, глубина ≤ 3), каждый кластер закреплён за одной страницей, фильтр-посадочные по образцу лидеров выдачи.

Ограничения: доступов к Яндекс.Вебмастеру, Search Console и Метрике домена нет (счётчиков на сайте нет). Привязка фото к моделям и габаритов к моделям не установлена: это вопросы к заказчику (CATALOG-MODEL.md §7).

## Следующие шаги

1. Утверждение дерева (5 решений в SITE-TREE.md) и ответы заказчика на 12 вопросов.
2. План перелинковки (INTERLINKING.md), финальная таблица Pages pipeline.
3. Дизайн и вёрстка (`/design-site`): направление дизайна, токены, шаблоны страниц из `drafts/content/` и `drafts/data/catalog.json`.
4. Обтравка фото на единый фон, запуск, 301 со старых URL, SEO-аудит после переезда.
