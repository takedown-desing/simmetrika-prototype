# Анализ текущего сайта simmetrika-mebel.ru — 2026-10-12 (pre-redesign baseline)

Сырьё: `snapshots/2026-10-12/`. Полный инвентарь: `knowledge-base/raw/simmetrika-mebel.ru/current-site-inventory.md`.

## Итог
Сайт — статический экспорт Tilda 2019 года на shared-хостинге reg.ru: 4 HTML-страницы, товары в попапах, ни одной страницы товара, нет цен/фото/тканей. Поисковой видимости нет (Keys.so msk — пусто, ни одного вхождения в ТОП-10 по 10 якорным запросам). Терять при переезде нечего, кроме трёх URL категорий и возраста домена — редиректы обязательны, но «сохранение позиций» не является риском.

## P1 — критично (устраняется новым сайтом)
| # | Проблема | Факт | Решение в новом сайте |
|---|---|---|---|
| 1 | Нет страниц товаров | 19 карточек-попапов на 3 страницах | Отдельный URL на каждый товар `/catalog/{category}/{model}/` |
| 2 | Нет robots.txt и sitemap.xml | оба 404 | Автогенерация (ТЗ §11) |
| 3 | Нет H1/H2, title главной = домен | `<title>simmetrika-mebel.ru</title>`, заголовки в div | Шаблоны title/H1 по типам страниц (см. CATALOG-MODEL.md) |
| 4 | Дубль хоста www | `https://www.simmetrika-mebel.ru/` → 200 | 301 www → без www |
| 5 | Пустой canonical | `<link rel="canonical" href="">` | Self-canonical на каждой странице |
| 6 | Нет аналитики | счётчиков Метрики/GA в HTML нет | Новые счётчики + цели на 4 типа заявок + ecommerce (ТЗ §10) |
| 7 | Нет микроразметки | JSON-LD отсутствует | Organization/FurnitureStore + LocalBusiness (точки) + Product/Offer + BreadcrumbList |
| 8 | Битая ссылка Instagram → google.com | в футере всех страниц | Убрать (Instagram в РФ запрещён) |

## P2 — важно
- Мобильная скорость: Performance 71, Speed Index 7.7 s, TBT 520 ms; картинки JPG без WebP/lazy-load. Цель ТЗ: 2–3 с.
- Доступность 62/100 (контраст, alt).
- Телефонов четыре, в ТЗ «2 телефона» — определить основной/дополнительный и привязать к точкам.
- Точек продаж на сайте 5, в ТЗ — «2 шоурума» — подтвердить список.
- Контент: отсутствует описание моделей, тканей, механизмов, сроков изготовления, условий доставки.
