3. Модель каталога: категория → товар → вариант

Трёхуровневая структура из ТЗ, дополненная полями, без которых не собираются подборки, фильтры и микроразметка. Всё редактируется из админки.

Категория
  • name, slug (латиница, фиксируется при создании)
  • h1, title, description, вводный и SEO-текст
  • порядок, активность
  • На старт: прямые, угловые, модульные; новые — из админки
Товар = модель в категории
  • name, slug, одна категория; model_family связывает «Эджио прямой» и «Эджио угловой»
  • габариты Д×Г×В, высота посадки, спальное место
  • механизм: нет / пантограф / венеция / выкатной
  • наполнитель, каркас, опоры, описание
  • цена «от» = минимум по вариантам
  • флаги: хит, выставочный образец (+ старая цена), теги подборок
  • свои h1 / title / description
Вариант
  • ткань из справочника (материал, коллекция, цветовая группа, сватч)
  • сторона угловой секции: левая / правая
  • размерное исполнение (если есть)
  • цена, наличие: в наличии / под заказ N дней
  • фотогалерея варианта, артикул
Заявка
  • тип: корзина / в один клик / вопрос / обратный звонок
  • имя, телефон, email, комментарий, согласие 152-ФЗ
  • состав: вариант, количество, цена на момент заявки
  • страница-источник, UTM, статус (новая / в работе / закрыта)
  • email менеджерам + выгрузка CSV

Фильтры категории (ТЗ §5)

  • Цена (диапазон) — только если цены публикуются
  • Длина, см
  • Материал обивки: велюр, рогожка, жаккард
  • Цвет: 10 групп
  • Наличие
  • Сортировка: популярность (по умолчанию), цена по возрастанию и убыванию

Подборки формируются автоматически

  • Диваны-кровати: механизм ≠ «нет»
  • Большие диваны: длина ≥ 250 см
  • Пантограф / венеция / выкатные: по полю «механизм»
  • Велюр, рогожка, цвета: по справочнику тканей вариантов
  • В наличии: хотя бы один вариант in_stock
  • Распродажа: флаг «выставочный образец»

4. URL, индексация, редиректы

Правила адресов

  • Строчные буквы, латиница, дефисы, слэш на конце, без .html
  • Товар: /catalog/{category}/{product}/; вариант своего адреса не имеет, выбирается на странице (ссылка с ?variant= допустима, canonical на товар)
  • Транслит моделей: Эджио → edzhio, Кембридж → kembridzh, Реймонд → reymond, ТЭО → teo, Клоуд → kloud, Оксфорд → oksford, Милано → milano, Бомбей → bombey, Флоид → floyd, Роллинг → rolling, Тейлор → teylor, Шанхай → shanhay
  • Адрес фиксируется при первой публикации; любая смена — только 301

Что индексируется

  • Статические подборки и фильтры из карты: свой H1, текст, self-canonical, в sitemap
  • Автоправило: в выборке меньше трёх товаров → noindex,follow
  • Любые другие комбинации фильтров и сортировка — GET-параметры с noindex,follow и canonical на чистый адрес
  • Пагинация ?page=N индексируется, self-canonical; «показать ещё» с запасной ссылкой
  • /zayavka/ и «спасибо» — noindex; пустая категория отдаёт 200 с подсказкой, но noindex

6. Текущий сайт: что фиксируем до переезда

Статический экспорт Tilda 2019 года на хостинге reg.ru: четыре HTML-страницы, товары открываются в попапах. Органической видимости нет, поэтому риск потери позиций при переезде отсутствует; переносим только три адреса категорий и возраст домена.

8. Вопросы к заказчику, без которых не начать наполнение

  1. Цены. Публикуем ли цены «от …» по вариантам? Без них не работают фильтр и сортировка по цене, Offer в микроразметке и спрос «недорого / цена».
  2. Фото. Таблица соответствия для 75 кадров: файл → модель → категория → ткань → цвет → сторона. Сейчас подписан только один кадр («диван Bombay»).
  3. Точки продаж. На сайте 5 адресов (Химки ТЦ Гранд, Твой Дом 24 км МКАД, Империя на Дмитровском, Три Кита на Луговой, Roomer на Ленинской Слободе), в ТЗ — два шоурума. Актуальный список, часы, телефон и координаты каждой точки.
  4. Телефоны. Четыре номера на сайте: какой основной, какой для обратного звонка, есть ли WhatsApp или Telegram.
  5. Ткани. Справочник: названия коллекций, материал, цвета, сватчи, свойства (антикоготь, износостойкость).
  6. Характеристики моделей. Подтвердить таблицу «модель → габариты → механизм» (на старом сайте привязка нестрогая), наполнитель, каркас, опоры, гарантию.
  7. Наличие и сроки. Что реально в наличии; срок изготовления под заказ после «сокращения сроков».
  8. Эджио и Egeo. В материалах есть каталог итальянской CTS Salotti (модель Egeo). Какая связь и можно ли упоминать итальянский дизайн.
  9. Доступы. Яндекс.Вебмастер и Google Search Console домена, аккаунт reg.ru, владелец домена. Счётчики создаём новые.
  10. Юрлицо. Название, ИНН/ОГРН, адрес производства — для политики, футера и Organization.
  11. Ассортимент. На фото есть кресла и пуфы — добавляем категории? Нужна ли страница для дилеров и оптовиков?
  12. Соцсети. Instagram убираем. Актуальны ли VK, Telegram, Дзен?
