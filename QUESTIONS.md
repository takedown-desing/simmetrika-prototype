# QUESTIONS.md — реестр вопросов к заказчику и рабочих допущений

> Живой документ проекта. Пополняется по мере работы: каждый новый вопрос получает номер, причину, рабочее допущение и статус. Пока ответа нет, в структурах и контенте используется допущение из колонки «Рабочее допущение», и такое место помечается в черновиках как `[ДОПУЩЕНИЕ Q-NN]`. Когда клиент отвечает, допущение заменяется ответом, статус меняется на «закрыт», а все места с пометкой `[ДОПУЩЕНИЕ Q-NN]` правятся.

**Статусы:** `открыт` — ответа нет, работаем по допущению · `уточняется` — вопрос передан клиенту · `закрыт` — ответ получен и внесён в проект.

**Как пополнять:** новая строка в таблицу блока по теме → номер следующий по порядку (Q-13, Q-14 …) → в колонке «Где используется» перечислить файлы, которые придётся править после ответа.
