## Сквозные решения, на которые опираются все структуры

- Общие блоки (шапка, футер, крошки, формы, 4 типа заявок) — `drafts/_CONTEXT.md §2`.
- Правила URL, индексации, canonical, редиректов — `research/structure/CATALOG-MODEL.md §2, §5`; дополнения модели данных — `§1 «Дополнения»`.
- Перелинковка — `INTERLINKING.md`; каждая структура в разделе 8 ссылается на него.
- Разделитель в title/description — `|` или `:`; длинное тире запрещено (D-01).
- Правило индексации подборок: ≥ 3 товаров → index, иначе `noindex,follow` (исключение `/sale/`, D-02).

## Что делать перед сборкой

1. Получить ответы на `QUESTIONS.md` (хотя бы Q-01 цены, Q-04 габариты, Q-06 ткани, Q-09 точки, Q-15 фото) и заменить допущения.
2. Снять недостающие данные из списка в конце `QUESTIONS.md` (выдача по «на заказ»/«доставка», проверка названий моделей, скриншоты конкурентов).
3. `/page-content` по структурам → тексты в `drafts/content/`, затем `/design-site`.
