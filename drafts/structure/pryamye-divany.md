## 1. Моделирование интерпретации запроса поисковым ИИ (P01 Шаг 1)

Запрос для моделирования: `[ТИП СТРАНИЦЫ: категория интернет-магазина] + [ЗАПРОС: диван прямой / прямые диваны купить (Москва)]`. Контекст выдачи — `research/serp/yandex-top10-2026-10-12.md` («прямой диван купить»: lemanapro, pushe, mnogosna, mebelvia, divano /ekonom-klass/, moon, sale-mebeli, mnogomeb, divan.ru, divanchik — все URL-ы категорий, ни одной статьи).

### 1.1 Сущности и атрибуты (NER)

1. **Диван** — тип мебели (класс «мягкая мебель»); нормализованная форма «диван», лемма покрывает «диваны», «диван-кровать», «диванчик».
2. **Прямой** — атрибут формы корпуса (линейный, одна секция, без угловой/оттоманки). Антонимы в онтологии: угловой, П-образный, модульный. Это главный дифференциатор запроса.
3. **Раскладной / нераскладной** — бинарный атрибут трансформации; раскрывается через сущности «механизм» и «спальное место».
4. **Механизм трансформации** — именованные значения в кластере: пантограф (111), выкатной (189), венеция (39); остальные (еврокнижка, аккордеон, книжка) — не в ассортименте (B02).
5. **Спальное место** — атрибут с числовым значением Ш×Д см (запросы «200 200», «140х200», «спальное место 140»).
6. **Размер / длина** — числовой атрибут (120, 130, 140, 150, 160, 170, 180, 190, 200, 220, 230, 240, 250, 300, 2200); «трёхместный / двухместный» — дискретный синоним длины.
7. **Ящик для белья / хранение** — атрибут комплектации («с ящиком» 939, «с хранением» 289).
8. **Обивка** — материал (велюр, рогожка, шенилл, вельвет, букле, антивандальный) и **цвет** (серый 721, бежевый 445, зелёный, коричневый, оливковый, синий, чёрный, белый, бордовый, терракотовый, голубой, оранжевый).
9. **Опоры** — «на ножках», «на высоких ножках»; **подлокотники** — «с подлокотниками», «узкие», «деревянные».
10. **Коммерческие маркеры** — купить, цена, недорого, каталог, в наличии, от производителя / фабрика / напрямую; **гео** — Москва.
11. Неявные атрибуты: доставка, срок изготовления, гарантия, помещение (гостиная 206, прихожая, балкон), стиль (лофт 313, сканди, современный, дизайнерский).

### 1.2 Онтология и таксономия

1. Таксономическая ветка: Товары → Мебель → Мягкая мебель → Диваны → **Прямые диваны** (узел по форме). Соседние узлы того же уровня: Угловые диваны, Модульные диваны.
2. Пересекающиеся фасеты (не подузлы, а срезы): по трансформации (диваны-кровати ↔ коллекция C05; механизмы C10/C11/C12), по обивке (C06/C07/C09), по цвету (C17), по размеру (C20), по назначению (C18 гостиная), по стилю (C19), по наличию (C21).
3. Ключевые узлы онтологии: «Производитель/фабрика» (SIMMETRIKA ↔ главная C01), «Шоурум» (5 точек ↔ C15), «Доставка/сборка» (C16), «Изготовление на заказ по размеру» (C13), «Распродажа образцов» (C14).
4. Отношение «модель ↔ исполнение»: одна модель (Эджио, Кембридж, Реймонд, Милано, Бомбей) существует как прямой и как угловой/модульный товар (`model_family`) — ИИ ожидает кросс-ссылку.
5. Отношение «механизм → спальное место → пригодность для ежедневного сна»: пантограф и венеция — ежедневный сон; выкатной — гостевой/ежедневный (`_CONTEXT §3`).
6. Отношение «длина → количество мест → помещение»: 200–260 см = трёхместный = гостиная; меньшие размеры — запрос на `/na-zakaz/`.
7. Атрибуты конструкции (каркас, пружинный блок/змейка, ППУ, опоры) — узлы доверия/EEAT `[ДОПУЩЕНИЕ Q-05]`.
8. Внешние бренды и чужие модели в хвосте (трентон, карина, бостон, марсель, scandica, гуд мебель) — навигационные узлы других сайтов; на странице не используются.

### 1.3 Интент и фокус внимания (salience)

1. Основной интент — транзакционный: выбрать и купить прямой диван в Москве (маркеры «купить» в 30+ фразах, «цена», «недорого», «каталог»).
2. Вторичные: сравнительный (раскладной vs нераскладной; прямой vs угловой — вопрос из FAQ divan.ru), справочный по размерам (длина, спальное место), локальный («москва», «от производителя»).
3. Распределение внимания: «прямой» (0,35 — дифференциатор формы), «диван» (0,25 — объект), «раскладной / кровать / спальный / механизм» (0,20), «купить / цена / недорого» (0,12), «Москва / производитель» (0,08).
4. Связи в запросе: «прямой» модифицирует «диван» (форма); «раскладной» → подразумевает «механизм» и «спальное место»; «с ящиком» → «хранение»; «трёхместный» → «длина ≥ 200»; цвет/ткань → варианты товара.
5. Ожидаемый формат результата (по выдаче): листинг товаров с ценой и фильтрами, а не статья; текстовые блоки и FAQ — вспомогательные.
6. Гео-привязка: запрос геозависимый — ИИ подмешивает локальные магазины и шоурумы Москвы; сигнал «шоурумы в Москве и Химках» повышает релевантность.
7. Уровень цены: «недорого», «эконом-класс» (divano ранжируется подстраницей `/ekonom-klass/`) — ожидание ценника на карточке.

### 1.4 Внутреннее представление и ожидания ИИ

1. Нормализованная форма: «каталог прямых (линейных, не угловых) диванов, в том числе раскладных диванов-кроватей, с ценами, размерами, механизмами и возможностью купить в Москве от производителя».
2. Чек-лист ожиданий от контента: (а) список моделей с фото, ценой «от», габаритами и механизмом; (б) фильтры по цене, длине, обивке, цвету, наличию; (в) объяснение раскладной/нераскладной и трёх механизмов; (г) размеры и спальные места в сантиметрах; (д) ткани и цвета; (е) условия: доставка, сроки, гарантия, оплата; (ж) где посмотреть вживую; (з) FAQ; (и) ссылки на соседние категории и подборки.
3. Сигналы релевантности: «прямой/прямые» в H1, title, названиях карточек и alt; числовые значения (см, ₽, дни); термины «пантограф», «венеция», «выкатной», «спальное место», «нераскладной», «трёхместный»; «Москва», «от производителя», «фабрика»; разметка `CollectionPage` + `ItemList` + `FAQPage`.
4. Неоднозначность 1: «прямой» в хвосте встречается как «напрямую от производителя» (15–33 WS) — закрывается фразой «напрямую с фабрики» в SEO-тексте, без отдельного блока.
5. Неоднозначность 2: «диван с прямой спинкой» (159), «диван с прямым углом» (60) — на самом деле про конструкцию спинки/угловой диван; игнорируем, не оптимизируем.
6. Неоднозначность 3: «диван прямой выкатной» — пользователь ищет и форму, и механизм; закрывается карточкой Оксфорд + ссылкой на `/catalog/divany-krovati/vykatnye/`.
7. Неоднозначность 4: размеры 120–190 см — в ассортименте нет; ИИ ожидает либо товар, либо ответ «изготовим на заказ» → ссылка на `/na-zakaz/` в блоке размеров и FAQ.
8. Концептуальная уверенность: высокая (≈0,9), интент однозначно коммерческий, тип страницы — категория каталога; остаточная неопределённость — доля «диван-кровать»-интента внутри (≈25% фраз кластера содержат раскладной/кровать/спальный).

## 2. Прикладные рекомендации (P01 Шаг 2)

### 2.1 Содержание: сущности, атрибуты, связи

1. Сущность «прямой диван» раскрыть через атрибуты формы (линейный корпус, ставится у стены, занимает ширину 200–260 см, глубину 96–116 см `[ДОПУЩЕНИЕ Q-04]`).
2. Восемь моделей как именованные сущности с одинаковым набором атрибутов: Д×Г×В, спальное место, механизм, цена «от», ткани/цвета, наличие (`_CONTEXT §3`).
3. Три механизма как сущности с определением в 1–2 предложения (из `_CONTEXT §3`): пантограф, венеция, выкатной — и список моделей на каждый.
4. Связь «раскладной → спальное место → ежедневный сон»: явно указать размеры 150×200, 160×190, 150×215 и для каких моделей.
5. Связь «нераскладной → гостиная»: Эджио и Бомбей как диваны для гостиной без механизма; перекрёстная ссылка на `/catalog/divany-dlya-gostinoy/`.
6. Связь «длина → места → помещение»: 202–210 см (Клоуд, Оксфорд) — компактные трёхместные; 230–240 (Бомбей, Кембридж, ТЭО, Эджио); 250–260 (Реймонд, Милано) — большие, ссылка на `/catalog/bolshie-divany/`.
7. Обивка: велюр, рогожка, жаккард с краткими свойствами и цветовыми группами `[ДОПУЩЕНИЕ Q-06]`; ссылки на `/catalog/pryamye-divany/velyur/`, `/catalog/rogozhka/`, `/catalog/cvet/{color}/`.
8. Производитель: SIMMETRIKA — фабрика, производство в Московской области `[ДОПУЩЕНИЕ Q-11]`, контроль качества, сертифицированные материалы (оффер с текущего сайта), гарантия 18 мес. `[ДОПУЩЕНИЕ Q-05]`.
9. Условия: доставка 1 500 ₽ по МКАД, сроки 1–3 дня в наличии / 14–21 день под заказ, предоплата 30% `[ДОПУЩЕНИЕ Q-02, Q-14]`; шоурумы — 5 точек `[ДОПУЩЕНИЕ Q-09]`.
10. Не раскрывать: чужие модели из хвоста, еврокнижку/аккордеон (нет в ассортименте), происхождение дизайна и зарубежные прототипы `[Q-07]`.

### 2.2 Структура страницы: отражение таксономии и интента

1. Порядок сверху вниз повторяет приоритет интента: сначала транзакция (H1 → intro → фильтры → листинг → CTA), затем справочная часть (подборки → размеры → механизмы → ткани → конструкция → условия → шоурумы), затем навигация (соседние категории) и FAQ.
2. Обязательные разделы: листинг с карточками; панель фильтров; блок «Подборки» (внутренние SEO-посадочные); H2 «Раскладные и нераскладные»; H2 «Размеры»; H2 «Механизмы» с тремя H3; H2 «Ткани и цвета»; H2 «От производителя: конструкция и гарантия»; H2 «Доставка»; H2 «Шоурумы»; H2 «Смотрите также»; H2 FAQ (последний).
3. Элементы: таблица «модель × длина × спальное место × механизм × цена от» (ИИ-извлекаемая); список 3 механизмов (определения); две инфографики (шкала длин; схема механизмов); FAQ-аккордеон с `FAQPage`; чипы подборок; хлебные крошки.
4. Таксономическое положение показывается тремя способами: крошки (Главная → Каталог → Прямые диваны), блок «Смотрите также» (угловые, модульные, диваны-кровати), блок «Подборки» (фасеты внутри категории).
5. Не делать: статейные H2 про «историю диванов», отзывы-модуль (вне ТЗ), «в других городах» (одна гео-зона).

### 2.3 Тип контента / формат

Категория интернет-магазина (листинг с фильтрами) + короткий intro-текст над листингом (50–80 слов) + структурированный SEO-текст под листингом (H2/H3, таблица, списки) + FAQ. Формат товара в листинге — карточка-плитка. Текстовая часть служебная: раскрывает фасеты и отвечает на вопросы, не конкурирует с листингом за первый экран.

### Проработка SEO-текста (каталожная страница)

- **Где стоит:** два текстовых слоя. Intro над листингом (под H1): 50–80 слов, одна ссылка на `/catalog/`, упоминание «8 моделей», «раскладные и нераскладные», «от производителя». Основной SEO-текст — под листингом и блоком «Подборки», после CTA-перебивки.
- **Объём основного текста:** 500–700 слов (без FAQ), разбит на H2/H3 ниже; каждый подраздел 60–120 слов + таблица/список.
- **H2/H3 внутри SEO-текста:** «Раскладные и нераскладные прямые диваны: что выбрать» (H3 для сна / H3 для гостиной) → «Размеры прямых диванов: длина 200–260 см и спальное место» (H3 какой длины / H3 спальное место) → «Механизмы трансформации» (H3 пантограф / венеция / выкатной) → «Ткани и цвета обивки» → «Прямые диваны от производителя: конструкция и гарантия».
- **Факты, которые должны войти:** 8 моделей с Д×Г и спальным местом (`_CONTEXT §3`), определения 3 механизмов (`_CONTEXT §3`), 3 материала и 10 цветовых групп (`_CONTEXT §4`), каркас/наполнитель/опоры/гарантия 18 мес. (`_CONTEXT §3`, Q-05), доставка 1 500 ₽ и сроки 14–21 день (`_CONTEXT §7`), 5 шоурумов (`_CONTEXT §5`).
- **Запрещено в тексте:** ценовые обещания сверх «от N ₽» `[Q-01]`, конкретные плотности тканей/Мартиндейл `[Q-06]`, тема из `[Q-07]` (происхождение дизайна), восклицания.

## 10. Паттерны для ИИ-извлечения и featured snippet

1. **Определение** (intro, первые 40–60 слов под H1): «Прямой диван — … линейный корпус 200–260 см … раскладной с механизмом или нераскладной …» — цель сниппета для «диван прямой» / «виды прямых диванов».

3. **Список** (H2 «Механизмы», 3 пункта с определениями по 1 предложению): цель — «какой механизм дивана лучше для ежедневного сна» (PAA), «диван прямой механизмом».
4. **Числовые факты** (блок 14 и 13): 1 500 ₽, 1–3 дня, 14–21 день, 18 месяцев, 30% — в виде коротких строк «параметр: значение».

## 11. Доступность

- Один `<h1>`; иерархия H2 → H3 без пропусков; названия товаров в карточках — не заголовки (`<a>` внутри `<article>` с `aria-labelledby`).
- Landmarks: `<header>` (шапка), `<nav aria-label="Основное меню">`, `<nav aria-label="Хлебные крошки">`, `<main>` (от H1 до FAQ включительно), `<aside aria-label="Фильтры">` (панель фильтров на десктопе; на мобильном — `<dialog>`), `<footer>`.
- Фильтры: каждый `<input>` с `<label>`; группы — `<fieldset><legend>`; range-слайдеры дублируются числовыми полями; сортировка — `<select>` с label «Сортировка»; счётчик результатов в `aria-live="polite"`.
- «Показать ещё» — `<button>` + реальная `<a href="?page=2">` для no-JS; при подгрузке фокус переходит на первую новую карточку.
- Кнопки «В заявку» — `<button type="button" aria-label="Добавить диван Эджио в заявку">`; тост в `role="status"`.
- FAQ — `<details><summary>`, Enter/Space, видимый `:focus-visible` (outline 2 px, контраст ≥ 3:1).
- Alt у всех фото по шаблону; декоративные SVG инфографик — `role="img"` с `aria-label` + текстовые подписи в DOM.
- Контраст текста ≥ 4.5:1, цены и бейджи ≥ 4.5:1; тап-цели ≥ 44×44 px (сватчи 44 px, чипы 36 px высотой с отступом 8 px → суммарная цель 44).
- Формы: ошибки текстом рядом с полем + `aria-describedby`; маска телефона не ломает скринридер (`inputmode="tel"`).
- Цель Lighthouse Accessibility ≥ 95, Performance mobile ≥ 85 (LCP ≤ 2,5 с: первая карточка без lazy, остальные lazy).

### 13.3 Пагинация / сортировка / фильтры

- 8 товаров < 20 → пагинация не рендерится; компонент `LoadMore` включается автоматически при > 20 (`?page=N`, self-canonical, index, fallback-ссылка).
- Сортировка меняет только GET `?sort=price_asc|price_desc` → noindex + canonical на категорию; дефолт «популярность» — без параметра.
- Фильтры → GET noindex; одиночный материал «велюр» → индексируемый `/catalog/pryamye-divany/velyur/`; одиночный цвет → остаётся GET (цветовые посадочные глобальные `/catalog/cvet/{color}/`, перекрёстной ссылкой — из блока «Подборки»).
- Фильтр «Длина» при 8 товарах: чипы диапазонов информативнее слайдера; на 390 px — чипы.

### 13.4 Пустое состояние

HTTP 200, `noindex,follow` (для пустой категории) · сообщение · ссылки на три другие категории/коллекции · «Сбросить фильтры» (для пустой выборки) · телефон. Сохраняем H1 и крошки; SEO-текст и FAQ при пустой категории не выводим (чтобы не ранжировать страницу без товаров).

### 13.5 Состояние «нет цены» `[Q-01]`

Если `price_from = null`: карточка показывает «Цена по запросу» вместо «от N ₽», фильтр «Цена» и сортировки по цене скрываются, в `CategoryHero` маркер «от N ₽» не выводится, description-шаблон без «Цены от … ₽», `ItemList` без `Product/Offer`. FAQ 8 переформулируется в «Как узнать цену».

### 13.6 Вариант без фото `[Q-15]`

Карточка с плейсхолдером (силуэт прямого дивана, SVG, брендовый фон) + бейдж «Фото скоро»; alt — по шаблону без ткани/цвета. Hero категории при отсутствии кадра — не выводить (блок схлопывается до H1 + intro).

### 13.7 Local (NAP)

На категории NAP выводится блоком 15 (5 точек) и футером; `LocalBusiness` ×5 — только на `/kontakty/` (CATALOG-MODEL §4), на категории — `Organization.address` главного шоурума `[Q-09]`.

### 13.8 Образцы со скидкой

Если в категории есть товары `is_sample_sale = true` — бейдж «Образец −N%» на карточке и чип «Распродажа образцов» → `/sale/` `[Q-03]`.
