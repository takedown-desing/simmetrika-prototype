### 1.1 Сущности и атрибуты (NER)

1. **Модульный диван** — тип продукта (мебель › мягкая мебель › диваны › модульные). Нормализованная форма: «модульный диван» = «модульная система сидений» = «секционный диван» (в карте: «диваны секционные модульные» 24, «диваны модульной системы» 25, «модульный диван конструктор» 25).
2. **Модуль / секция** — составная часть: прямая секция (ширина 80/100/120/130 см по контексту §3), угловой модуль, оттоманка (пуф-продолжение сиденья), подлокотник (съёмный у Эджио), секция с механизмом (Бомбей). Атрибуты: ширина, глубина, наличие спинки/подлокотника, механизм.
3. **Композиция (конфигурация)** — результат сборки модулей: прямая, угловая, П-образная («п образный диван» 363 + 157 + 140 + 55 + 36 + 32), с оттоманкой / шезлонгом. Атрибуты: общая длина × глубина, число посадочных мест, ориентация (левая/правая).
4. **Форма** — явный атрибут в запросах: «угловой» (1 345 + 222 + 113 + 59 + 54 + 53), «прямой» (311 + 105 + 69 + 37), «п образный», «большой» (158 + 61 + 51 + 37 + 35).
5. **Спальное место / механизм** — «раскладной» (373 + 113 + 105), «диван кровать» (205 + 52 + 37), «спальный» (84). Сущности-механизмы: пантограф (у Бомбея), венеция, выкатной.
6. **Помещение** — «для гостиной» (328 + 75 + 56 + 55 + 50 + 37 + 35), «в гостиную» (53 + 24). Атрибуты: размер комнаты, стена, свободная планировка.
7. **Обивка / цвет** — «велюр» (76 + 24), «букле» (25), «серый» (74 + 24), «бежевый» (40), «зеленые» (37), «коричневый» (27), «антивандальный» (24), «цвет диванов модульные» (81).

### 1.2 Онтология и таксономия

1. **Активированная таксономическая ветка:** Товары › Мебель › Мягкая мебель › Диваны › Модульные диваны (сестринские узлы: прямые, угловые, диваны-кровати). Вышестоящая: мебель для гостиной.
2. **Узел «производитель / фабрика»:** ИИ связывает «модульный диван» с сущностью «мебельная фабрика» (Москва) и ожидает атрибуты производителя: собственное производство, срок изготовления, гарантия, шоурумы, изготовление по размерам.
3. **Отношение «состоит из»:** модульный диван → модули (секция, угол, оттоманка, подлокотник) → материалы (каркас, наполнитель, ткань). Это главное онтологическое отличие от «обычного дивана»: отношение part-of должно быть явно раскрыто.
4. **Отношение «имеет форму»:** модульный диван → композиция (прямая / угловая / П-образная / с оттоманкой) → габариты. Форма не фиксирована, в отличие от узлов «угловой диван» и «прямой диван», где форма — определяющий атрибут.
5. **Отношение «имеет функцию сна»:** модульный диван → (опционально) секция с механизмом → спальное место. В онтологии это ветка «диван-кровать»; для модульных она необязательна, что и порождает вопрос PAA «Можно ли спать на модульном диване?».
6. **Отношение «размещается в»:** модульный диван → гостиная / зона отдыха / открытая планировка → размер стены, угла, центра комнаты.
7. **Смежные сущности сайта:** угловые диваны (Эджио и Бомбей существуют в угловой категории через `model_family`), большие диваны от 250 см (все три системы в базовой композиции ≥ 235 см), диваны с пантографом (Бомбей), диваны для гостиной (коллекция C18), диваны на заказ (композиция под размер = тот же интент).
8. **Коммерческие сущности:** цена «от», наличие / под заказ, доставка, сборка (у модульных особенно важна), шоурум, заявка.

### 1.3 Интент и фокус внимания (salience)

1. **Основной интент:** транзакционный с предварительным исследованием («купить модульный диван» в Москве, посмотреть варианты, цены, фото).
2. **Вторичные интенты:** (а) информационный — что такое модульный диван, чем отличается, минусы, можно ли спать; (б) навигационный к форме — «угловой модульный», «П-образный», «прямой модульный»; (в) локальный — «модульные диваны москва», где посмотреть вживую.
3. **Salience:** наибольший вес у «модульный» (определяющий признак, отделяет от сестринских категорий), затем «диван» (класс), затем модификаторы формы («угловой», «п образный») и функции («раскладной», «кровать»). «Купить» и «Москва» — коммерческий и гео-контекст с меньшим семантическим весом, но обязательные для ранжирования в Яндексе по гео.
4. **Семантические связи в запросе:** «модульный» → атрибут конструкции (сборный из модулей); «угловой модульный» → форма композиции, а не класс; «модульный диван кровать» → композиция, включающая секцию с механизмом; «модульные диваны для гостиной» → помещение как ограничение по размеру и стилю.
5. **Ожидаемый тип результата:** категория-листинг с фильтрами и ценами + объясняющий текст; ИИ понижает чисто информационные страницы (блог) и чисто карточки одной модели.
6. **Региональность:** запрос геозависимый (в карте «москва» 291 + 238 + 59 + 54): ИИ ожидает подтверждения локальности — адреса шоурумов, доставка по Москве и области.
7. **Фокус пользователя на фото:** модульные диваны выбирают по визуалу композиций в интерьере; без фотографий разных конфигураций страница воспринимается как неполная.

### 1.4 Внутреннее представление и ожидания ИИ

1. **Нормализованная форма запроса:** «Купить модульный диван (угловой / прямой / П-образный, со спальным местом или без) от производителя в Москве: модели, модули, композиции, цены, фото, шоурумы».
2. **Чек-лист ожиданий от контента:** определение модульного дивана (1–2 предложения); перечень модулей с размерами; примеры композиций (минимум прямая, угловая, П-образная, с оттоманкой); список моделей с ценой «от» и габаритами базовой композиции; ответ про сон (какие модули с механизмом); как выбрать под комнату (замер, число мест); ткани и цвета; доставка, сборка, срок изготовления; адреса шоурумов; FAQ; фото в интерьерах.
3. **Сигналы релевантности:** H1 с «модульные диваны»; H2 с формами композиций и словом «модули/секции»; таблица модулей с числами (см); наличие `CollectionPage` + `ItemList` с 3 Product; цены в рублях; топонимы Москва, Химки, МКАД; FAQ с вопросами PAA слово-в-слово; альты изображений с названиями композиций.
4. **Неоднозначность 1 — «модульные системы»:** термин из ТЗ пересекается с системами хранения; снимается H1 «Модульные диваны и системы» и первым абзацем-определением (см. раздел 0).
5. **Неоднозначность 2 — «модульный угловой диван» vs категория «угловые диваны»:** ИИ может считать запросы взаимозаменяемыми; снимается кросс-ссылкой на `/catalog/uglovye-divany/` и явным объяснением «угловая композиция собирается из модулей, а готовый угловой диван имеет фиксированную форму».
6. **Неоднозначность 3 — «раскладной модульный»:** у нас только Бомбей с пантографом; ИИ ожидает отдельного ответа, иначе сочтёт страницу нерелевантной «диван модульный раскладной» (373). Снимается H2 «Можно ли спать…» и ссылкой на `/catalog/divany-krovati/pantograf/`.
7. **Неоднозначность 4 — конфигуратор:** «модульный диван конструктор» (25) и «Собрать» у divan.ru формируют ожидание интерактива; 3D-конфигуратор вне ТЗ (§12). Снимается блоком «Соберите свою композицию» (заявка с параметрами) — пользователь получает тот же результат (подбор композиции), но через менеджера.
8. **Концептуальная оценка уверенности:** высокая (0,85+) для классификации «коммерческая категория мебели», средняя (0,6) для подинтентов формы и сна — поэтому страница должна покрывать все четыре формы и вопрос сна явно, а не оставлять это карточкам.
9. **Риск «тонкой» страницы:** 3 товара — ИИ может оценить витрину как бедную относительно лидеров (pushe, divan.ru с десятками позиций). Компенсация: подкарточки композиций (8–12 вариантов с собственными фото, размерами и ценами) и объясняющий контент; это и есть уникальное преимущество фабрики (композиция под размер), а не недостаток.

### 2.2 Структура страницы: отражение таксономии и интента

- **Обязательные разделы:** (1) H1 + вводный текст-определение; (2) листинг 3 систем; (3) галерея готовых композиций; (4) «Что такое модульная система»; (5) «Из каких модулей собирается» — таблица; (6) «Примеры композиций» — 4 карточки + инфографика раскладки; (7) mid-content CTA «Соберите свою композицию»; (8) «Как выбрать под комнату» — нумерованный список-шаги; (9) «Можно ли спать»; (10) фото в интерьерах; (11) ткани и цвета; (12) модели в других исполнениях; (13) доставка / сборка / сроки; (14) шоурумы; (15) FAQ последним.
- **Структурные элементы:** таблица модулей (сущность-связь), таблица сравнения трёх систем (габариты, модули, спальное место, цена «от»), нумерованный список выбора (сниппет), 2 инфографики (раскладка модулей; путь покупки), FAQ `details/summary` + `FAQPage`, галерея композиций как карточки-ссылки.
- **Порядок:** коммерческие блоки (листинг, композиции) выше объясняющих — интент транзакционный; объяснение сразу после листинга, чтобы не отправлять пользователя в блог; CTA в середине, после «Примеров композиций», когда пользователь уже понял, что ему нужна «своя» сборка.
- **Фильтры:** компактная панель по ТЗ §5 (цена, длина, материал, цвет, наличие) + специфичный переключатель «Со спальным местом»; при 3 товарах фильтры свёрнуты по умолчанию на мобильном.

### 2.3 Тип контента / формат

Категория интернет-магазина фабрики: листинг + «витрина композиций» + объясняющий SEO-контент с таблицами и FAQ. Не статья, не лендинг одной модели. Формат ближе к oneandhome.ru (три объясняющих H2) и pushe.ru (FAQ-блок), но с визуальной витриной композиций вместо длинного списка товаров.

## 5. FAQ (14 Q/A)

Напоминание: HTML (`details/summary`) и `FAQPage.mainEntity` — слово-в-слово; ответы 40–60 слов пишет копирайтер по заготовкам ниже.

1. **Чем модульный диван отличается от обычного?**
   Заготовка: модульный диван собирается из отдельных секций, угловых модулей и оттоманок, которые можно переставлять и докупать; у обычного дивана форма и размер заданы на производстве. Источник: `_CONTEXT §3` (состав модулей систем). PAA слово-в-слово.
2. **В чём минус модульного дивана?**
   Заготовка: композиция стоит дороже готового дивана сопоставимой длины (от 185 000 ₽ против прямых от 72 000 ₽), занимает больше площади, а спальное место есть только у секций с механизмом (у нас — Бомбей). Источник: `_CONTEXT §3` `[ДОПУЩЕНИЕ Q-01, Q-04]`. PAA слово-в-слово.
3. **Можно ли спать на модульном диване?**
   Заготовка: да, если в композицию входит секция с механизмом; у системы Бомбей секции с пантографом раскладываются в ровное спальное место для ежедневного сна; Шанхай и Эджио — для сидения. Источник: `_CONTEXT §3` `[ДОПУЩЕНИЕ Q-04]`. PAA слово-в-слово.
4. **Какой механизм у дивана самый надёжный?**
   Заготовка: для ежедневного сна в модульных секциях используем пантограф — сиденье поднимается и выдвигается вперёд, не царапает пол, даёт ровное место; в прямых и угловых моделях также венеция и выкатной. Источник: `_CONTEXT §3` (механизмы). PAA слово-в-слово.
5. **Где можно купить модульный диван в Москве?**
   Заготовка: в пяти шоурумах SIMMETRIKA — ТЦ «Гранд» в Химках, «Твой Дом» на 24 км МКАД, «Империя» на Дмитровском шоссе, «Три Кита», МЦ Roomer — или через заявку на сайте с обратным звонком менеджера. Источник: `_CONTEXT §5` `[ДОПУЩЕНИЕ Q-09]`. PAA слово-в-слово.
6. **Из каких модулей состоит модульный диван SIMMETRIKA?**
   Заготовка: прямые секции (80–130 см в зависимости от системы), угловой модуль, оттоманка (у Шанхая 100×100 см), съёмные подлокотники у Эджио и секции с пантографом у Бомбея. Источник: `_CONTEXT §3` `[ДОПУЩЕНИЕ Q-04]`.
7. **Какие композиции можно собрать?**
   Заготовка: прямую вдоль стены, угловую с левым или правым углом, П-образную для большой гостиной и композицию с оттоманкой вместо шезлонга; базовые варианты — Шанхай 330×160, Бомбей 300×150, Эджио 235×116. Источник: `_CONTEXT §3`.
8. **Как подобрать размер модульного дивана под комнату?**
   Заготовка: измерьте стену и угол, оставьте проход 70–80 см `[ДОПУЩЕНИЕ: норматив прохода — Q-19]`, проверьте ширину дверного проёма для заноса модулей, затем отправьте размеры в форме «Соберите свою композицию» — менеджер подберёт набор модулей. Источник: блок 11 `[Q-18]`.
9. **Можно ли докупить модуль позже?**
   Заготовка: да, модули систем изготавливаются под заказ и совместимы в рамках одной системы; ткань подбирается из той же коллекции, срок изготовления 14–21 день. Источник: `_CONTEXT §7` `[ДОПУЩЕНИЕ Q-02; совместимость и сохранность коллекций тканей — Q-21]`.
10. **Сколько стоит модульный диван от производителя?**
    Заготовка: цены на базовые композиции начинаются от 185 000 ₽ (Шанхай), 190 000 ₽ (Эджио) и 210 000 ₽ (Бомбей); итоговая стоимость зависит от набора модулей и ткани, точную цену называет менеджер. Источник: `_CONTEXT §3` `[ДОПУЩЕНИЕ Q-01]`.
11. **Сколько ждать изготовления модульного дивана?**
    Заготовка: под заказ 14–21 день, выставочные образцы из шоурумов — доставка 1–3 дня. Источник: `_CONTEXT §7` `[ДОПУЩЕНИЕ Q-02]`.
12. **Как доставляют и собирают модульный диван?**
    Заготовка: доставка по Москве в пределах МКАД 1 500 ₽, за МКАД плюс 40 ₽/км; подъём с лифтом бесплатно, без лифта 300 ₽/этаж; сборка модульных композиций включена в стоимость. Источник: `_CONTEXT §7` `[ДОПУЩЕНИЕ Q-02, Q-14]`.
13. **Какие ткани подходят для модульного дивана?**
    Заготовка: велюр (мягкий, антикоготь, легко чистится), рогожка (износостойкая, для семей с детьми) и жаккард (плотный, с рисунком); 10 цветовых групп от серого и бежевого до синего и терракота. Источник: `_CONTEXT §4` `[ДОПУЩЕНИЕ Q-06]`.
14. **Подойдёт ли модульный диван для небольшой гостиной?**
    Заготовка: да, если собрать прямую композицию из двух секций или угловую без оттоманки; самая компактная база — Эджио 235×116 см, а под нестандартную стену композицию подберут по размерам. Источник: `_CONTEXT §3`; ссылка на `/na-zakaz/`.

- **Пустая категория (все 3 товара выключены):** 200 + сообщение + ссылки в другие категории (ТЗ §5) + `noindex` (CATALOG-MODEL §5); текстовые блоки 8–13 остаются, чтобы страница не теряла ценность.
- **Защита индекса при 1–2 активных товарах:** категория остаётся `index` (это не фильтр-посадочная), но админка показывает предупреждение «в категории меньше 3 товаров» `[НОВЫЙ ВОПРОС Q-17: вводить ли композиции как варианты, чтобы витрина не пустела]`.
- **Нет цены (`price_from` null) `[Q-01]`:** в карточке «цена по запросу», кнопка «Узнать цену» вместо «В заявку» не вводится — «В заявку» остаётся (заявка без цены допустима), в schema `Product` без `offers`; факт-плитка «от 185 000 ₽» в hero и description заменяется на «цены от производителя».
- **Вариант без фото `[Q-15]`:** подкарточка композиции не выводится в блок 7 (условие `photos.length > 0`); в листинге используется обложка товара; если у товара нет фото — плейсхолдер со схемой композиции (SVG из инфографики 1).
- **Local (NAP):** блок 18 дублирует 5 адресов с телефонами из `_CONTEXT §5` `[Q-09]`; `LocalBusiness` на каждую точку размечается только на `/kontakty/`, здесь — `Organization` с адресом главного шоурума.
- **Сторона угла (L/R):** в модульных задаётся композицией (`size_label` содержит «левая/правая»), поле `variant.side` допустимо использовать для угловых композиций — согласовать с CATALOG-MODEL (поле описано как «только для угловых») `[НОВЫЙ ВОПРОС Q-17]`.
- **301 со старого сайта:** `/modular.html → /catalog/modulnye-divany/` (CATALOG-MODEL §5).
- **Отключённый 3D-конфигуратор (ТЗ §12):** вместо него блок 11; в текстах не обещать «соберите онлайн», формулировка «подберём композицию по вашим размерам».
