## 1. Моделирование интерпретации запроса поисковым ИИ (P01 Шаг 1)

### 1.1 Сущности и атрибуты (NER)

1. Сущность «диван» (тип: предмет мебели, класс «мягкая мебель»), нормализованная форма «диван». Главная сущность кластера.
2. Атрибут формы «угловой» (конфигурация: Г-образная, две секции под углом 90°). Нормализация: «угловой диван» = «диван угловой» = «диван уголок» (фраза «угловой диван углу», 1 567, и «мягкий уголок» у divan.ru).
3. Атрибут «сторона угла» (левый / правый), явный в 10+ фразах: «угловой диван левый» (879), «угловой диван правый» (668), «угловой диван левый угол» (573), «правый угол» (424). Неявный атрибут для всего кластера: ИИ ожидает, что у углового дивана есть параметр стороны.
4. Атрибут «спальное место / раскладной / кровать»: «угловой диван кровать» (4 062), «диван угловой раскладной» (3 817), «спальные диван угловой» (3 111), «для ежедневного сна» (129+198). Связанная сущность: механизм трансформации (пантограф, венеция, выкатной).
5. Атрибут «размер»: «угловой диван размеры» (1 103), «большой угловой диван» (1 674), числовые модификаторы 150 / 180 / 200 / 210 / 220 / 230 / 240 / 250 (суммарно ≈ 1 700). ИИ ожидает таблицу габаритов и спальных мест.
6. Атрибут «место применения»: «в гостиную» (2 909 + 878 + 750), «в комнату» (282), «дома» (240). Таксономическая связь с коллекцией «Диваны для гостиной» (C18).
7. Атрибут «цена / недорого»: «угловой диван недорого» (1 905), «цена» (943), «недорого москва» (713). ИИ ожидает цены «от» и ценовой фильтр.
8. Атрибут «гео»: «москва» (3 602 + 2 913), «московской области» (210). Локальный интент: шоурумы, доставка по Москве и области.
9. Атрибут «источник / производитель»: «от производителя» (511 + 417), «фабрика диванов» (569), «производители угловых диванов москва» (304). Сущность-организация: фабрика SIMMETRIKA.
10. Атрибуты обивки и цвета: «серый» (932), «бежевый» (449), «зеленый» (329), «коричневый» (310), «кож» (192, нет в ассортименте), «мягкий» (434), «с подушками» (265), «на ножках» (466), «с ящиками / с хранением» (765 + 262 + 220 + 180; данных по ящикам в контексте нет, см. раздел 14).

### 1.2 Онтология и таксономия

1. Активированная таксономическая ветка: Товары → Мебель → Мягкая мебель → Диваны → Угловые диваны. Страница занимает узел «Угловые диваны» и является дочерней к `/catalog/` (хаб «Каталог диванов», C00).
2. Соседние узлы той же ветки: Прямые диваны (`/catalog/pryamye-divany/`, C02), Модульные диваны и системы (`/catalog/modulnye-divany/`, C04). ИИ ожидает явного противопоставления «угловой vs прямой» (вопрос divan.ru «Чем угловой диван отличается от прямого?») и перехода «угловой → модульный» для больших композиций.
3. Поперечные (сквозные) узлы: Диваны-кровати (C05) и фильтры механизмов пантограф (C10), венеция (C11), выкатные (C12); Большие диваны от 250 см (C20); Диваны для гостиной (C18); фильтры тканей велюр (C06, C08) и рогожка (C07); цвета (C17); в наличии (C21).
4. Онтология «угловой диван» → части: основная секция, угловая секция (угол), оттоманка/шезлонг (удлинённая секция без спинки), подлокотники, подушки спинки, опоры (ножки), механизм трансформации, бельевой ящик (атрибут, данных нет).
5. Онтология «сторона угла»: отношение «угол расположен слева/справа, если смотреть на диван сидя или стоя лицом к нему». Разные магазины трактуют по-разному, ИИ знает про неоднозначность и ищет явное правило на странице.
6. Онтология «спальное место» → атрибуты: ширина × длина (150×215 … 153×300 у SIMMETRIKA), механизм (пантограф / венеция), пригодность для ежедневного сна, ровность поверхности.
7. Онтология «организация»: фабрика-производитель (SIMMETRIKA) → производство в Московской области `[ДОПУЩЕНИЕ Q-11]` → 5 точек продаж в мебельных центрах `[ДОПУЩЕНИЕ Q-09]` → доставка и сборка (§7 контекста).
8. Процессная онтология покупки (ТЗ §7): выбрать модель → выбрать ткань и сторону → добавить в заявку → звонок менеджера → доставка/самовывоз. Без онлайн-оплаты.
9. Ключевые внешние ориентиры для узла в выдаче: pushe.ru (угловые для ежедневного сна), divan.ru (фильтры и 16 FAQ), mnogomeb.ru, anatomiyasna.ru, mebelvia.ru, m-lion.ru (три SEO-H2), ozon/hoff (маркетплейс/гипермаркет).

### 1.3 Интент и фокус внимания (salience)

1. Основной интент: транзакционно-навигационный «купить угловой диван в Москве» через каталог с фильтрами и ценами. В ТОП-10 по «угловой диван купить» только категории-листинги (pushe, mnogomeb, anatomiyasna, divan.ru), ни одной статьи.
2. Вторичные интенты: (а) сравнить размеры и спальные места; (б) определить нужную сторону угла; (в) убедиться, что диван подходит для ежедневного сна; (г) найти «от производителя / недорого»; (д) посмотреть вживую в шоуруме.
3. Распределение внимания: «угловой» (форма) ≈ 45 %, «диван» ≈ 25 %, «купить/цена/недорого» ≈ 15 %, «Москва» ≈ 10 %, «кровать/раскладной/спальный» ≈ 5 % в головной фразе, но до 30 % по хвосту.
4. Семантические связи: «угловой» модифицирует «диван» (тип), «купить» задаёт транзакцию, «Москва» задаёт гео, «кровать/раскладной» добавляет функциональность, «левый/правый» уточняет конфигурацию товара.
5. Сигнал ранжирования из SERP: pushe.ru ранжируется первым с H1 «Угловые диваны для ежедневного сна в Москве», то есть ИИ считает «спальная функция» и «Москва» сильными сопутствующими признаками для коммерческой категории.
6. Фокус на листинге: ИИ ожидает в первом экране список товаров с ценами, а не текст. Текст (SEO-блок, FAQ) — под листингом.
7. Отрицательные фокусы: статьи-гайды, обзоры «лучшие угловые диваны» (277) — информационный хвост, его закрывает блог C22 (отложен), не эта страница.

### 1.4 Внутреннее представление и ожидания ИИ

1. Расширенная форма запроса: «каталог угловых диванов [со спальным местом] [левый/правый угол] с ценами от производителя, купить в Москве с доставкой, посмотреть в шоуруме».
2. Чек-лист ожиданий от контента: (1) список моделей с фото, ценой «от», габаритами; (2) фильтры по цене, длине, материалу, цвету, наличию и стороне угла; (3) объяснение «левый/правый угол»; (4) таблица размеров и спальных мест; (5) механизмы трансформации и пригодность для ежедневного сна; (6) ткани и цвета; (7) информация о производителе, гарантии, доставке, сборке; (8) адреса шоурумов в Москве; (9) FAQ; (10) ссылки на смежные подборки.
3. Ключевые сигналы релевантности: лемма «угловой диван» в H1, title, первом абзаце, alt, названиях товаров («Угловой диван Эджио»); присутствие слов «левый», «правый», «сторона угла», «спальное место», «пантограф», «венеция», «оттоманка», «Москва», «шоурум», «от производителя», «цена от».
4. Структурные сигналы: `CollectionPage` + `ItemList` с 8 товарами, `BreadcrumbList` (Главная → Каталог → Угловые диваны), `FAQPage`; таблица с числовыми габаритами; списки.
5. Неоднозначность 1: «угловой диван» vs «модульный диван с угловым модулем». Обработка: на странице явно отделить категорию от модульных систем и дать ссылку на `/catalog/modulnye-divany/` для сборных композиций (Эджио и Бомбей есть в обеих категориях через `model_family`).
6. Неоднозначность 2: конвенция «левый / правый угол» (вид сидя или вид стоя). Обработка: одно правило на странице, инфографика, одинаковая формулировка в фильтре, карточках и FAQ `[новый вопрос N-08]`.
7. Неоднозначность 3: «угловой диван кровать» может означать как категорию, так и коллекцию «Диваны-кровати». Обработка: страница закрывает запрос подразделом «со спальным местом» и ссылается на `/catalog/divany-krovati/` для всех типов.
8. Неоднозначность 4: числовые модификаторы «угловой диван 200/180/150» — это длина или спальное место. Обработка: в таблице размеров указывать обе величины и подписывать единицы.
9. Концептуальная уверенность ИИ в интерпретации: высокая (≈ 0,9) для коммерческого категорийного интента; средняя (≈ 0,6) для разбора стороны угла и размеров — страница должна снять именно эти сомнения.

### 2.2 Структура страницы: отражение таксономии и интента

1. Первый экран: крошки → H1 «Угловые диваны» → интро 50–80 слов (кол-во моделей, диапазон размеров, стороны угла, цена «от») → чипы подборок → фильтры → листинг. Это зеркалит ТОП-10 (у всех лидеров листинг сразу под H1).

6. Схема: `CollectionPage` + `ItemList` + `BreadcrumbList` + `FAQPage` + `Organization` в одном @graph (раздел 6).
7. Отражение таксономии в навигации: крошки показывают родителя `/catalog/`; блок «Соседние категории» показывает братьев (прямые, модульные); блок «Подборки» показывает поперечные узлы (диваны-кровати, пантограф, венеция, большие, велюр, цвета).

## 5. FAQ (14 Q/A)

Напоминание: HTML (`summary` = вопрос, `p` = ответ) и `FAQPage.mainEntity` слово-в-слово. Ответы в финале 40–60 слов; ниже заготовки 1–2 предложения.

1. **Как понять, какой угол дивана нужен: левый или правый?**
   Заготовка: встать лицом к дивану (или к стене, где он будет стоять) и посмотреть, с какой стороны окажется угловая секция; если слева, нужен левый угол, если справа, правый. На странице схема и подсказка в фильтре «Сторона угла». Источник: конвенция стороны `[новый вопрос N-08]`, схема раздела 9.

2. **Можно ли поменять сторону угла после покупки?**
   Заготовка: сторона выбирается при заказе как вариант товара (левая или правая), у каждой модели доступны обе `[новый вопрос N-01]`; переставить угол у собранного дивана с фиксированной угловой секцией нельзя, поэтому сторону стоит проверить по плану комнаты до оформления заявки. Источник: ТЗ §4 (вариант = сторона), `[новый вопрос N-01, N-04]`.

3. **Чем угловой диван отличается от прямого?**
   Заготовка: угловой диван состоит из двух секций под прямым углом и даёт больше посадочных мест и более длинное спальное место при той же стене; прямой занимает одну стену и подходит для узких комнат. Модели Эджио, Кембридж, Реймонд, Милано, Бомбей выпускаются в обоих исполнениях. Источник: _CONTEXT §3 (таблицы прямых и угловых, `model_family`).

4. **Какие размеры у угловых диванов SIMMETRIKA?**
   Заготовка: длина от 235 см (Флоид) до 353 см (Бомбей), глубина от 105 до 205 см; полная таблица по 8 моделям выше на странице. Источник: _CONTEXT §3 `[ДОПУЩЕНИЕ Q-04]`.

5. **Как подобрать угловой диван под размер комнаты?**
   Заготовка: измерить две стены, вдоль которых встанет диван, и сверить с длиной и глубиной модели в таблице; для раскладных моделей учесть место под разложенное спальное место (150–153 см в ширину). Если стандартные размеры не подходят, диван изготовят по вашим размерам. Источник: _CONTEXT §3, ссылка `/na-zakaz/`.

6. **Какой угловой диван выбрать для маленькой комнаты?**
   Заготовка: самые компактные в категории Флоид (235×116 см) и Милано (245×162 см); Милано при этом раскладывается в спальное место 153×222 см. Источник: _CONTEXT §3 `[ДОПУЩЕНИЕ Q-04]`.

7. **Какой угловой диван подходит для ежедневного сна?**
   Заготовка: модели с механизмами пантограф (Кембридж, Бомбей, Роллинг) и венеция (Эджио, Реймонд, Милано, Тейлор) рассчитаны на ежедневное раскладывание и дают ровное спальное место; без спального места в категории только Флоид. Источник: _CONTEXT §3 «Механизмы».

8. **Чем отличаются механизмы пантограф и венеция?**
   Заготовка: у пантографа сиденье поднимается и выдвигается вперёд «шагом», не касаясь пола; у венеции сиденье выдвигается, а спинка опускается на освободившееся место. Оба подходят для сна каждый день. Источник: _CONTEXT §3 «Механизмы».

9. **Какое спальное место у угловых диванов?**
   Заготовка: от 150×215 см (Кембридж) до 153×300 см (Эджио); у Бомбея и Роллинга 150×300 см, у Реймонда 150×280, у Милано 153×222, у Тейлора 150×260 `[нет данных, допущение]`. Источник: _CONTEXT §3 `[ДОПУЩЕНИЕ Q-04]`.

10. **Сколько стоит угловой диван от производителя?**
    Заготовка: цены на угловые диваны SIMMETRIKA начинаются от 128 000 ₽ (Флоид) и доходят до 172 000 ₽ «от» (Бомбей); точная цена зависит от ткани и уточняется менеджером после заявки. Выставочные образцы продаются со скидкой до 30 %. Источник: _CONTEXT §3 `[ДОПУЩЕНИЕ Q-01]`, §1 акции `[ДОПУЩЕНИЕ Q-03]`.

11. **Где посмотреть угловые диваны вживую в Москве?**
    Заготовка: в пяти точках продаж: ТЦ «Гранд» в Химках (главный шоурум), ТЦ «Твой Дом» на 24 км МКАД, ТЦ «Империя» на Дмитровском шоссе, ТЦ «Три Кита» и МЦ Roomer; адреса и часы на странице контактов. Источник: _CONTEXT §5 `[ДОПУЩЕНИЕ Q-09]`.

12. **Какую ткань выбрать для углового дивана в семье с детьми или животными?**
    Заготовка: велюр с эффектом антикоготь легко чистится, рогожка износостойкая и фактурная; обе ткани есть в 6–9 цветовых группах. Источник: _CONTEXT §4 `[ДОПУЩЕНИЕ Q-06]`.

13. **Входит ли сборка в доставку углового дивана?**
    Заготовка: да, сборка угловых диванов включена; доставка по Москве в пределах МКАД 1 500 ₽, за МКАД плюс 40 ₽/км, подъём без лифта 300 ₽ за этаж. Источник: _CONTEXT §7 `[ДОПУЩЕНИЕ Q-02, Q-14]`.

14. **Сколько ждать угловой диван под заказ?**
    Заготовка: модели в наличии доставляют за 1–3 дня, изготовление под заказ занимает 14–21 день (по акции 14 дней), стандартный срок 30 дней; при заказе под размер предоплата 30 %. Источник: _CONTEXT §7 `[ДОПУЩЕНИЕ Q-02]`.

Не включать (нет данных): ящик для белья, вес дивана, нагрузка на спальное место, кожа.

## 13. Особые случаи

- **Пагинация:** при ≤ 20 товарах скрыта; шаблон держит `?page=N` (self-canonical, index, «показать ещё» с fallback-ссылкой).
- **Сортировка:** `?sort=price_asc|price_desc` → `noindex,follow`, canonical на категорию; по умолчанию популярность (`sort`, `is_hit`).
- **Фильтры:** любые GET-комбинации (`side`, `price`, `length`, `sleeping`, `material`, `color`, `availability`) → `noindex,follow` + canonical; единственный индексируемый статический фильтр категории — `/catalog/uglovye-divany/velyur/` (≥ 3 товаров → index). Фильтр «Сторона угла» при одном выборе не меняет URL-логику (GET, noindex).
- **Пустое состояние фильтра:** «По выбранным параметрам угловых диванов нет» + кнопка «Сбросить фильтры» + 3 ссылки (все угловые, диваны-кровати, диван на заказ); 200, `noindex`.
- **Пустая категория** (все товары выключены): сообщение + ссылки в прямые, модульные, диваны-кровати (ТЗ §5), 200, `noindex`.
- **Нет цены** (`price_from = null`) `[ДОПУЩЕНИЕ Q-01]`: в карточке «Цена по запросу», кнопка «Узнать цену» = «Заказать в один клик»; фильтр и сортировка по цене скрываются, если цен нет у ≥ 50 % товаров; в description «Цены от …» заменяется на «Цена по запросу у менеджера».
- **Нет фото** `[ДОПУЩЕНИЕ Q-15]`: плейсхолдер с силуэтом углового дивана и подписью модели; карточка не скрывается; alt остаётся по шаблону.
- **Сторона угла по умолчанию в карточке листинга:** показывать обложку первого активного варианта; бейдж «Л / П» сообщает о доступности обеих `[новый вопрос N-01]`.
- **Модели без спального места (Флоид):** строка характеристик «без спального места · с оттоманкой»; не попадает в коллекцию диваны-кровати.
